# 导出可见模型

v0.4.4 在顶部工具栏提供 **导出模型**，可将当前可见装配保存为 GLB 或二进制 STL。需要保留组件类型、交互参数、电路和可继续仿真的工程时，使用旁边的 **保存项目**，生成 `.mechanical.json`。

## 操作

1. 在主视图调整姿态和显隐。**内部**可隐藏外壳，**隐藏导线**可同时隐藏源线束与逻辑连线，也可在装配树中逐件隐藏。
2. 点击 **导出模型**，选择格式，再点击 **导出 GLB** 或 **导出 STL**。
3. 桌面版使用系统保存窗口选择文件位置；浏览器开发版发起文件下载。取消系统保存后，格式窗口保持打开，可重新导出。生成和保存期间不能重复导出或关闭格式窗口；失败信息会显示在窗口内。

| 格式 | 单位 | 保留内容 |
| --- | --- | --- |
| GLB（默认） | 米；工作台毫米坐标按 0.001 转换 | 可见网格、零件名称及网格层级、PBR 材质与纹理 |
| 二进制 STL | 坐标按毫米写入；导入其他软件时选择毫米 | 可见三角面；不保留颜色、材质或零件层级 |

导出记录点击格式导出按钮时的主视图快照，包含当前位姿、弹簧显示变形和显隐状态；开启爆炸视图时也会导出分离后的显示位置。后台继续运动不会改变已经取得的快照。功能组件查看弹窗的分层间距不属于主视图，不写入模型。

隐藏零件及其不可见子网格不导出。导线开启时包含可见的源线束模型和逻辑连线表面；关闭后两者均不导出。地板、参考网格、灯光、相机、选中框、触点标记和其他编辑辅助对象不包含在文件中。

GLB 保留零件原有 PBR 外观；碰撞提示红色与透视模式的临时透明效果不会写入材质。

## 当前边界

- 单个文件最多 **256 MiB**；超出时可隐藏部分零件后重试。没有可见模型表面时不能导出。
- 可见素材尚未载入或载入失败时会拒绝导出，不把占位体当作实际模型。请先等待加载完成或处理失败素材；隐藏的未加载素材不会阻止其余模型导出。
- 骨骼网格、实例化网格和正在生效的 morph 变形目标暂不支持，应先在建模软件中烘焙为静态网格。工作台自身的弹簧显示变形已支持快照导出。
- 导出的是显示网格与当前外观，不是原始 Blender 高精度源件、运动动画或制造验证报告。GLB/STL 不携带可恢复的组件功能与接线语义，不能替代工程文件或源网格验证证据。
