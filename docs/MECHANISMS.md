# 多零件功能组件

素材树中的“配套小组”只记录零件关系；“组成功能组件”会另外建立 `Project.mechanisms`，把多个独立子件定义为可以运行的按压回弹或插销配合机构。子件保留自己的模型、名称、颜色和 PBR 材质，统一的功能代理负责接触与运动检查。

## 创建与角色

选中相关零件后打开“组成功能组件”，明确指定每个成员的角色：

- **活动件**：可以有多个，例如键帽、与它相连的撞针、标识。它们按刚体关系同步移动和旋转。
- **固定件**：例如套筒和外壳，至少一个。组件按压或插入时保持原位；整体定位时随组件框架一起移动。
- **弹簧**：按压组件可指定多个弹簧显示件。运行时沿真实组件轴压缩，中心移动半个压缩量，固定端保持不动。它们不作为独立刚体参与簧圈接触求解。
- **开关**：按压组件可选择一个固定子件作为两端子常开触点，撞针实际进入声明的触发区域后闭合，分离后断开。原模型即使属于结构件也能明确指定为触点。

每个子件只能属于一个功能组件。活动件不能仍设置为“固定”；固定基座不会阻止按压。整体定位要求先解除成员上的固定锁。组件成员不能单独移动或删除，要使用组件控制或先编辑成员关系。电源、灯和电阻保留独立电路行为；已有导线的开关必须明确设为该组件的开关角色，不能静默丢失连接。

## 框架、轴与代理

`frame.position` 和 `frame.rotation` 定义组件世界坐标框架，单位为 mm 和 XYZ 欧拉角度。`axis` 是该框架内的单位方向：按压沿 **负 axis**，配合操作的正位移沿 **正 axis**，正角度按该轴的右手方向旋转。

活动与固定代理各自声明 `kind`、局部 `position` / `rotation`、`size` 和数值 `params`。位置、旋转相对于组件框架；销和孔代理的自身 Y 轴须与组件操作轴同向。按压组件可使用长方体实体包络；如果实际结构依赖孔腔，就应选择方榫/方孔或圆销/套筒代理并填写相应尺寸，不能用实心包络代替贯穿孔。

“按成员边界填入代理”只提供编辑起点，不会识别孔、卡耳、材料或已验证的配合。原始素材子件的旧“待配置”功能参数会由已完成的组件级代理接管，真实显示网格仍完整保留。代理与可视网格的对应关系需要人工核对；该软件不声称进行了精确网格接触认证。

## 按压回弹

必须填写总运动质量 `mass`（kg）、等效总刚度 `stiffness`（N/mm）、阻尼 `damping`（N·s/m）、最大行程 `travel`（mm）、自由长度 `freeLength` 和并圈高度 `solidLength`。最大行程不能超过自由长度减并圈高度。多个可视弹簧使用同一自由长度和压缩量，质量与刚度表示整个活动机构的等效参数。每个弹簧的尺寸包络沿组件世界轴的投影长度必须与 `freeLength` 一致，容差为 `max(0.001 mm, freeLength × 0.00001)`；不符时禁止运行，避免缩放与中心位移导致固定端漂移。

运行后按住组件控制中的按压按钮，使用 `1.1 × stiffness × travel` N 的输入力驱动质量、弹簧与阻尼模型；松开后外力归零并回弹。活动子件整体沿轴移动，弹簧长度按 `(freeLength - displacement) / freeLength` 显示。求解每步都会检查活动代理相对固定基座及邻近实体的路径，压下和回弹使用同样的碰撞检查；被实体阻挡时停止该步。自由位置和最大行程还限制压缩量在 `[0, travel]` 内。

状态存于运行时 `MechanismStates`，包括位移、速度与回弹力；不覆盖项目中的静止成员坐标。暂停保留当前运行状态，重置回到静止状态。采用孔/销代理的按压机构还需填写插入上限、最小余隙及双方公差，以验证实际滑动空间。

## 撞针与开关的几何接触

配置开关角色后，必须定义 `contact`；不带开关的普通弹簧组件无需接触点。接触定义包含活动撞针成员 `strikerPartId`、撞针端点 `strikerPoint`、固定开关触发点 `switchPoint`、开关面法向 `switchNormal`、有效触发半径 `radius` 和允许压入量 `maxOvertravel`。

两个点的坐标分别位于各自子件的局部坐标系，以零件显示包围盒中心为原点，单位为 mm。法向属于开关的局部坐标系，须为单位向量并朝向静止撞针。点须落在各自子件的尺寸包络内，整个有效触发圆盘也须位于开关包络内；不能把开关放在远处，再用悬空触发点或超大触发半径代替实际装配。组件整体定位、旋转、压下时，端点和法向随真实成员姿态变换到世界坐标。

令 `n` 为世界开关法向、`a` 为世界操作轴，当前法向间隙为 `gap = (strikerWorld - switchWorld) · n`。只有横向偏差不超过 `radius`、`gap ≤ 0` 且压入量 `-gap ≤ maxOvertravel` 时，开关才导通。触发位置由初始几何计算为 `initialGap / (a · n)`；旧 `params.trigger` 仅作为兼容数据保留，不再决定组合组件的通断。

完成配置时会检查静止点没有穿入、轴与法向同向、撞针路径命中触发区域、接触位置在行程内，并要求 `travel × (a · n) ≤ initialGap + maxOvertravel`，避免撞针越过开关允许压入范围。运行面板显示实际间隙、横向偏差及通断状态，视图标记撞针端点与触发点。验证报告记录实际发生的触发，不用理论行程代替接触。

接触点、触发面和允许压入量仍是用户声明的功能参数；这些检查不证明触发点恰在原网格表面，也不模拟开关材料形变。

## 插入与旋锁

配合组件支持方榫 / 贯穿方孔、圆销 / 套筒、标准双耳旋锁公母件。填写双方代理尺寸、公差、孔径或方孔宽深，以及 `insertionDepth`、`minClearance`；旋锁还需 `lockAngle = 45`。

组件控制可整体定位，也可只让活动公件组沿轴插入或绕轴旋转。活动组所有成员同步变换，母件组保持原位；每次操作都检查完整采样路径与最终配合，不能只检查终点。标准旋锁代理仍限定公件 `16 × 24 × 16 mm`、母件 `24 × 18 × 24 mm`：先对准入口、插入槽高、正转 45°，锁定后直接上拔会被实体挡住；先反转回入口才可退出。方榫旋转同样接受实体检查，不通过忽略碰撞来实现旋入。

`pose.offset` / `pose.angle` 记录配合活动组相对初始位置的累计轴向偏移与角度，受检操作同时更新真实子件姿态。新建组件的 `pose` 必须为零；已有组件不能通过配置表直接改 `frame` 或 `pose`。已插入或旋转的配合组件只允许改名称、配置状态；重新标定成员、轴或代理之前须先受检退回零位，避免只改代理而让显示子件留在原地。

## 数据与验证范围

项目导入会验证成员引用、角色不重叠、坐标、代理数据和机制唯一归属。未完成配置的组件可保存预览，但不能运行或通过仿真验证。UI 与 MCP 共同使用 [`src/mechanisms.ts`](../src/mechanisms.ts) 的场景映射、步进、移动、配置更新与验证函数。

运动路径使用最大代理顶点位移 ≤0.25 mm 的采样，不是连续碰撞保证。求解不包含通用刚体重力接触、摩擦、防松卡点、材料变形、簧圈接触、屈曲或有限元；原始确认键的旋锁网格也不会自动变成标准双耳代理。更多参数和限制见 [组件类型](COMPONENTS.md) 与 [验证说明](VALIDATION.md)。
