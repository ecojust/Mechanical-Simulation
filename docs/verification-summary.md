## v0.4.1 pureTV 源尺寸与实际 MCP 试验

原始手柄修正为183个独立子件，保留15个来源集合。真实 MCP 在工作台中建立九个按压组件、一个5 V电源、九盏100 Ω指示灯与27根导线，共193件。撞针在0.75 mm接触，1 mm总行程内触头最多随动0.25 mm，电气主体保持固定。逐键确认接触前断电、接触后仅对应灯亮且50 mA、释放后回弹断电，并读取实际Three对象的位姿与弹簧变形矩阵。

最终源文件的独立检查包括：

- 183个源对象、16,653个静止对象对及11,476个固定对象对；1,666个候选检查中1,468项无相交、198项限定在逐对象声明的局部接触区，没有未分类项。
- 20条线束全部通过严格自身相交检查，均闭合、单连通；修正回折与局部扫掠接缝，电气端点保持不变。
- 多键活动成员426对，其中418对由完整行程包围体分离排除，8对执行5×5共200个独立姿态组合。
- 九键360项内部采样；九组锁装、防脱、逆拆与安装辅助成员的5,824个正向及对应逆向姿态。
- 15个GLB、源哈希和目录一致性，以及九键弹簧端点与实际触面显示误差≤0.001 mm。

证据绑定具体源文件、GLB、当前装配、机构参数与接线；数据缺失、修改或范围不匹配时保持待验证。原始全场记录见 [整机源审计](puretv-geometry-assembly.json)，修形与假设见 [源几何说明](puretv-geometry.md)，操作见 [pureTV 试验](PURETV.md)。

软件验证包括265项单元测试、13组浏览器操作、7项Rust测试、35项源审计核心测试、方榫和旋锁各9项验证，以及TypeScript与生产构建。浏览器操作覆盖完整手柄的183个显示子件、源证据状态、触点点灯、真实弹簧变形矩阵、失焦释放和九键循环。官方MCP SDK验证19个工具、38次鉴权调用、超过16 MiB上传及分页工程导出。
