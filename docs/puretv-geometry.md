# pureTV 源尺寸与功能校准

尺寸测量使用 Blender 5.2.2 求值后的原始三角网格，不使用减面 GLB 证明局部配合。源坐标单位为 mm、Z 向上；客户端坐标是 `(source.x, source.z, -source.y)`。MCP 装配统一加 `[0,20,0]`，不能分别居中各子件。

柱塞规格是声明的圆杆 6×6/H4.3 执行件，实物采购必须匹配。不能拿原方杆开关配此圆孔并继续沿用通过结果。柱塞 0.25 mm 允许过行程是名义规格；其触发力、反作用力和实物额定行程尚未验证。

`puretv-calibration.json` 保存每键的源哈希、独立角色、世界接触点、弹簧端点与支承距离、真实包络、中心轴代理及质量/刚度/阻尼。`switchNode` 是物理柱塞触面，`electricalSwitchNode` 是固定开关主体，二者分开。0.75 mm 前不接触；之后柱塞随动，直到总行程 1 mm。电气闭合由真实变换后的撞针与触面决定。

中心轴代理只代表中央细杆和采样孔带。八键杆径约 D2.06583 mm，确认约 D3.09901 mm；代理不能表达外圈交错弧段、锁耳、肩部或壳体。代理 `insertionDepth` 取整个 0–1 mm 行程内的最大重叠长度，本版为 2 mm，而非按钮行程。源网格审计负责这些外围结构，不能用代理通过代替原网格结论。

弹簧上下支承最近见证距离：八键下端约 0.00082 mm、上端约 0.00015 mm；确认下端约 0.00871 mm、上端约 0.00149 mm。保留实际测量值，不篡改自由长度以掩盖间隙。并圈高度以 `(圈数+1)×最大线径` 保守估算，八键约 1.82337 mm、确认约 1.75 mm；这是几何估计，未认证实物弹簧。

运动质量假设均质 PLA 密度 1.24 g/cm³，并由源闭合键帽体积计算。ABXY 字母是零挤出装饰面，按无质量表面处理，不对其开放三角形计算伪实体体积。刚度使用钢的假设剪切模量 79,000 N/mm² 与源圈数、平均圈径、最大线径计算；源线径包络略有各向异性。阻尼比假设为 0.65。它们都不是力学实测。弹簧显示和源路径检查采用下端固定的轴向仿射变形，保持实测端点行程，并不是保持线截面的真实弹性变形或有限元计算。当前模型未纳入实物开关反力、摩擦、偏心卡滞、磨损或打印材料强度。

`puretv-geometry-internals-before.json` 保留修前证据；`puretv-geometry-internals-after.json` 记录九键在 0、0.25、0.5、0.75、1 mm 的内部三角相交与双向内部点检查。内部点以三方向有向射线确认，并保留位置与深度见证。触面接触及柱塞进入开关外形占位最多 0.25 mm 是具体对象对、局部区域限定的柔顺接口，不能泛化为允许任何实体穿透。

八个主键套筒与底板的源旋锁路径是 −25° 入口、压入原位以下 0.25 mm、转回 0°、回弹坐定，逆序拆出。确认座的母件是上盖，键帽与确认座之间保持按压导向；不能把可自由旋转的帽/座误标为旋锁公母。确认安装抬高 1 mm 后，保守弹簧并圈余量约 0.4898 mm。

24 个旋锁软垫的最终坐定界面已逐个测量并限定具体对象对与薄层区域，见 `puretv-geometry-pad-interfaces.json`。方向键垫自由厚度约 0.510 mm，两侧总预压约 0.010 mm（约 1.96%）；ABXY 垫自由厚度约 0.505 mm，总预压约 0.005 mm（约 0.99%）。但安装过程还要额外下压 0.25 mm，因此瞬时总压缩约 0.255–0.260 mm、约自由厚度的 50.5–51.0%，剩余几何厚度约 0.250 mm。它没有压至零厚，并不意味着某种材料已获准承受该应变。需要匹配软垫材料并实测装入力、非线性刚度、压缩永久变形与寿命；刚性锁路径的通过结论不包含这些材料验证，也不代表轻力装拆已经证实。

内部检查不等于整机通过。完整固定–固定、活动/弹簧–全部环境、卡口插入/旋转/拆出覆盖须由整机报告逐项确认。离散采样不是连续碰撞检测；采样最近距离也不是全局最小距离证明。最终状态只信任与当前源、显示 GLB、组件参数和位置同时匹配的证据。

复测：

```sh
blender -b --python scripts/calibrate-puretv.py
blender -b --python scripts/audit-puretv-internals.py -- --output docs/puretv-geometry-internals-after.json
blender -b --python scripts/export_assets.py
node scripts/index_asset_nodes.mjs
node scripts/verify_assets.mjs
node scripts/verify-puretv-calibration.mjs
```

修复脚本是针对修前源的迁移记录，不应重复对已经修正的文件叠加变形；源前后 SHA、局部尺寸和对象名在对应 JSON 中保留。
