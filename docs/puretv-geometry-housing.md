# pureTV 上盖滑动面检查与局部修正

本次读取 Blender 5.2.2 的完整求值源网格，未使用减面的 GLB。源坐标单位为 mm，客户端转换为 `(x, y, z) → (x, z, -y)`；下压对应源 `−Z` / 客户端 `−Y`，以下世界坐标不包含工作台整体抬升。

原始外部检查包含九个一体式键帽/插销、八个随动上弹簧定位环和四个随动 ABXY 标识，对上盖、底壳、两块底板及八颗固定螺钉，在 0、0.25、0.50、0.75、1.00 mm 共检查 1,260 个对象对姿态。未观察到三角表面交叉或双向包含采样的内部点证据。原始表面交叉使用全部源三角形；上盖为 1,231,844 三角形，底壳为 243,080 三角形。

没有名义穿插并不等于余隙足够。例如原上键静止时存在约 0.0232 mm 的轴向近点，左键滑动孔缘存在约 0.0422 mm 的横向近点。轴向近点可能属于上止挡，不能简单把整个开孔扩大。

## 修改范围

仅修改 `assets/puretv-controller/housing/top.blend` 内的 `pureTV · 按键区圆滑过渡上壳.002`。按壳面法向及最近点方向共同区分侧向滑动面和轴向止挡边；对前者施加局部 XY 避让，平滑邻域位移，并回退少量反向面。没有修改帽体外形、顶部露出高度或上盖任何 Z 坐标。

修改后的上盖仍为 615,906 个顶点、1,231,844 个三角形；源多边形拓扑保持。最大局部横移 0.313765 mm，轴向变化为零。检查得到边界边 0、非流形边 0、源多边形法向反转 0、退化三角形 0。九个帽体在上述五个姿态与修改后的上盖仍无三角表面交叉。

## 止挡保留

从原始帽体静止姿态的有效下表面见证点向上发射射线，修改后九键都仍命中上盖内装止挡：左 6/6、右 6/8、下 6/6、上 7/10；ABXY 每键 339/452；确认 196/225。比例表示原检测到止挡的离散样本中仍保留命中的数量，不表示真实接触面积。侧壁扩展减少了部分边缘覆盖，未将整个止挡移除；仍需后续整机网格检查与实体试装确认保持力、弹性及打印公差。
